# 🛰️ Curso CONAE – Herramientas avanzadas para la teledetección de recursos agrícolas y forestales

### Descripción

Curso de posgrado virtual organizado por la CONAE, orientado al procesamiento y análisis de datos de teledetección 
aplicados a recursos agrícolas y forestales. El trabajo final consistió en la ejecución y adaptación de un **script en R** 
(proporcionado por el docente, construido a partir de contribuciones de diversos autores) para procesar **nubes de puntos de vuelos de drones**.

### Proceso realizado

1. **Ejecución del script en R:** Se corrió el script sobre un conjunto de datos de nubes de puntos de drones.
2. **Procesamiento de nubes de puntos:** El script permitió limpiar, filtrar y analizar la nube de puntos, extrayendo información relevante 
para aplicaciones agrícolas y forestales.
3. **Análisis de resultados:** Se interpretaron las métricas obtenidas y se generaron gráficos y tablas para visualizar los resultados.

### Aprendizajes

- **Procesamiento de datos de drones:** comprensión de la estructura de una nube de puntos y su potencial para aplicaciones ambientales.
- **Uso de R para teledetección:** familiarización con librerías y funciones específicas para el análisis de datos de drones.
- **Interpretación de resultados:** capacidad de traducir datos crudos en información útil para la toma de decisiones.
- **Trabajo con scripts de terceros:** aprendizaje de la lectura, adaptación y ejecución de código desarrollado por otros, 
una habilidad clave en el trabajo colaborativo.

### Herramientas utilizadas

- **R** – Procesamiento y análisis de nubes de puntos.
- **Plataformas para planificación de vuelos de drone**
- **Cloud Compare** para el procesamiento de imágenes de drones.
- **Teledetección** – Conceptos y técnicas aplicadas a recursos agrícolas y forestales.
