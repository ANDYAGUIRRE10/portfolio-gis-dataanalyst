# Cartografías para Trabajos de Tesis

## 📌 Contexto

Esta carpeta reúne cartografías realizadas como apoyo a investigaciones académicas (tesis de grado o posgrado) que requerían representar información espacial de manera clara, rigurosa y adaptada a los objetivos de cada estudio.
Cada mapa surge de un proceso de colaboración con el/la autor/a de la tesis, donde el diálogo constante fue clave para entender qué quería mostrar, cómo quería mostrarlo y a quién estaba dirigido.

## 🎯 Enfoque de trabajo

Cada tesis tiene sus propias necesidades cartográficas (mostrar una distribución, analizar relaciones espaciales, ubicar el área de estudio, etc.). Por eso, no hay una receta única, cada mapa se (co)diseña a medida.

El proceso general suele ser:

1. **Escucha y comprensión:** entender qué quiere comunicar el/la autor/a y cuál es el mensaje principal del mapa.
2. **Propuesta inicial:** armar un borrador con una propuesta de representación (colores, símbolos, escala, recorte).
3. **Ida y vuelta:** ajustar según el feedback, probar alternativas, simplificar o agregar información según sea necesario.
4. **Versión final:** entregar un mapa que cumpla con los estándares académicos y sea claro para el jurado y lectores de la tesis.

---

## 🧠 Desafíos y aprendizajes

- **Traducir necesidades a decisiones cartográficas:** lo que el/la autor/a quiere expresar no siempre es fácil de representar visualmente. El diálogo es fundamental para encontrar la mejor forma.
- **Equilibrio entre rigor y claridad:** una tesis exige precisión, pero el mapa también debe ser comprensible para un jurado que no necesariamente es experto en cartografía.
- **Adaptación a cada investigación:** cada tema tiene sus particularidades; no se puede aplicar una plantilla fija.
- **La cartografía como herramienta de comunicación científica:** un buen mapa puede sintetizar hallazgos complejos y hacerlos accesibles.
- **El valor del ida y vuelta:** a veces la mejor versión de un mapa surge después de varias correcciones y pruebas. La paciencia y la escucha activa son tan importantes como las habilidades técnicas.
