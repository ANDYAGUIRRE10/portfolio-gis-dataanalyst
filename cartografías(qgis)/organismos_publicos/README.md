# Cartografía para organismos públicos

## Sobre esta sección

Esta sección reúne trabajos de cartografía y análisis geoespacial desarrollados en el marco de proyectos vinculados con organismos e instituciones del sector público.

El objetivo es documentar y presentar diferentes productos cartográficos, mostrando el uso de herramientas GIS para la representación, organización y análisis de información territorial.

La colección podrá incorporar trabajos relacionados con organismos provinciales, municipales y nacionales, así como otras iniciativas vinculadas con la gestión del territorio.

## Áreas de trabajo

Los proyectos pueden abordar diferentes temáticas, entre ellas:

- Cartografía de referencia y representación territorial.
- Organización y distribución espacial de elementos territoriales.
- Elaboración de mapas temáticos.
- Visualización de información geográfica para la gestión pública.
- Preparación de productos cartográficos para informes y documentos técnicos.

Las temáticas dependerán de las características y los objetivos de cada proyecto.

## Herramientas

**QGIS** es la herramienta principal para la preparación, el análisis y la elaboración de productos cartográficos.

Según las necesidades de cada proyecto, podrán incorporarse otras herramientas y tecnologías de análisis geoespacial.

## Organización

Los trabajos se organizan en subcarpetas, que permiten identificar los organismos o proyectos correspondientes.

Cada subcarpeta puede incluir una descripción del trabajo, los mapas generados, información sobre las herramientas utilizadas y, cuando corresponda, los archivos del proyecto QGIS.

## Documentación

Para cada trabajo se procurará documentar:

- Objetivo y contexto del mapa.
- Información geográfica utilizada.
- Herramientas y procedimientos aplicados.
- Características del producto cartográfico.
- Consideraciones relevantes para su interpretación.

## Consideraciones sobre los datos

Los archivos publicados dependerán de las condiciones de uso y las autorizaciones correspondientes.

En ocasiones se ocultará información respecto a la problemática que se trabje o datos en particular para resguardar información sensible que no pueda ser comaprtida. 

Cuando corresponda, se publicarán únicamente las vistas cartográficas o versiones de los proyectos que puedan compartirse.
