# 🏠 Fachada de Casa — Práctica de AutoCAD

## 📌 Descripción
Dibujo básico de la fachada frontal de una vivienda unifamiliar, 
realizado como práctica introductoria a AutoCAD 2D versión.

## 🎯 Objetivo
Familiarizarme con el entorno de AutoCAD, comandos esenciales de 
dibujo y edición, y la exportación de archivos DXF (formato clave 
para interoperabilidad con software GIS como QGIS o ArcGIS).

## 🛠️ Herramientas y comandos utilizados
- **Software:** AutoCAD (versión 2021)
- **Formato de salida:** DXF (compatible con QGIS / ArcGIS)

## 📂 Contenido de la carpeta
| Archivo | Descripción |
|---------|-------------|
| `Frente de casa.dxf` | Archivo editable del dibujo |
| `Frente de casa.png` | Captura del resultado final |

## 🔗 Relación con GIS
El formato **DXF** es ampliamente usado en flujos GIS para:
- Importar planos catastrales o de infraestructura a QGIS.
- Digitalizar sobre capas CAD.
- Convertir geometrías CAD → shapefile / GeoPackage.

## 📚 Contexto de aprendizaje
Práctica realizada tras completar un curso introductorio gratuito 
en YouTube. Forma parte de mi transición hacia un perfil GIS más 
completo, combinando habilidades de CAD y análisis espacial.
