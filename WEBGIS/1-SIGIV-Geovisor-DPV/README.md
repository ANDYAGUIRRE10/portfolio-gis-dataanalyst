# 🗺️ SIGIV — Geovisor Interno de la Dirección Provincial de Vialidad de Santa Fe

## 📌 Descripción
Geovisor web interno desarrollado para la **Dirección Provincial de Vialidad 
de Santa Fe (DPV)**, dentro del marco del **SIGIV (Sistema de Información 
Geográfica Integral Vial)**.

La herramienta permite visualizar y analizar la distribución de los más de 
**13.000 km de rutas provinciales**, sirviendo como apoyo a la **toma de 
decisiones** tanto de equipos técnicos como de autoridades políticas.

> ⚠️ Proyecto de uso interno. Las capturas mostradas son de carácter 
> ilustrativo y no exponen información sensible.

## 🎯 Objetivo
Centralizar, procesar y disponibilizar información geográfica vial de la 
provincia en un visor accesible vía navegador, reemplazando flujos de 
trabajo manuales y dispersos.

## 🛠️ Stack tecnológico
| Componente | Tecnología |
|------------|-----------|
| Base de datos espacial | PostgreSQL + PostGIS |
| Servidor de mapas | GeoServer |
| Servidor de aplicaciones | Apache Tomcat |
| Frontend | Leaflet, HTML, CSS, JavaScript |
| Visualización de datos | Chart.js |
| SIG de escritorio | QGIS |
| Transferencia de archivos | FileZilla |

## ✨ Funcionalidades
- Visualización de la red vial provincial (~13.000 km de rutas).
- Filtros y consultas por atributos.
- Mapas base configurables.
- Panel de estadísticas con gráficos dinámicos (Chart.js).
- Acceso interno vía navegador, sin instalación de software.
