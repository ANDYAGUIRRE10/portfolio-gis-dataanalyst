# DataStudio / Looker Studio

## 📌 Contexto

Esta carpeta reúne capturas de pantalla de **dashboards y visualizaciones de datos** desarrollados con **Looker Studio** 
(anteriormente conocido como Google Data Studio).

---

## 📊 ¿Qué encontrarás aquí?

- Capturas de **dashboards interactivos** con filtros, gráficos y mapas.
- Integración de datos provenientes de **planillas de cálculo, bases de datos y fuentes geoespaciales**.

---

## 🛠️ Habilidades y herramientas trabajadas

- **Looker Studio (Google Data Studio)** – Creación de dashboards y visualizaciones interactivas.
- **Conexión de fuentes de datos** – Google Sheets, bases de datos, archivos CSV.
- **Diseño de indicadores** – Selección y presentación de métricas relevantes para la gestión.
- **Visualización geoespacial** – Integración de mapas y datos territoriales en los tableros.
